# ことばの案内（初学者向け）

この教材では、むずかしいカタカナを減らし、**日本語で意味が通る言い方**を優先します。  
ツール名や公式の名前（`kubectl` / Pod / Minikube など）はそのまま使い、横にやさしい言い方を添えます。

## 言い換え一覧

| よくあるカタカナ | この教材での言い方 |
|------------------|-------------------|
| ハンズオン | **実習**（手を動かして確かめる手順） |
| シナリオ | **練習問題** / **想定ケース** |
| トラブルシュート | **障害の切り分け** |
| ポリシー | **方針** / **約束** |
| デプロイ | **配置して動かす** |
| マニフェスト | **YAML設定**（クラスタへの依頼書） |
| コンソール | **管理画面** |
| サンドボックス | **練習用の無料環境**（Developer Sandbox） |
| クラスタ | **計算機のまとまり**（クラスタ）。初出以外は「クラスタ」も可 |
| リソース | **もの** / **資源**（Pod や Service など） |
| ステータス | **状態** |
| エンドポイント | **届け先一覧**（Endpoints） |
| ラベル | **付箋**（ラベル） |
| セレクタ | **探す条件** |
| レプリカ | **複製の台数** |
| ネームスペース | **仕切り**（Namespace） |
| イメージ | **コンテナのひな形**（イメージ） |
| トークン | **一時の通行証** |
| アドオン | **追加機能** |
| トンネル | **橋渡し** |
| ドライバー | **動かしかた** |
| オペレーター | **運用を自動化する部品**（Operator） |
| クオータ | **利用上限** |
| ランブック | **毎週の手順書** |
| オプション | **追加の指定** |
| アナロジー | **たとえ** |

コマンド名・YAML のキー（`replicas` など）は英語のままです。説明文だけやさしくします。
